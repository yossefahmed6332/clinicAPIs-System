## 5. Functional Requirements

### Patient

- FR-001: The system shall allow patients to create an account.
- FR-002: The system shall allow patients to log in and log out.
- FR-003: The system shall allow patients to view available doctors.
- FR-004: The system shall allow patients to search for doctors based on their availability and specialization.
- FR-005: The system shall allow patients to book an appointment with an available doctor.
- FR-006: The system shall allow patients to view their appointments.
- FR-007: The system shall allow patients to cancel an appointment.
- FR-008: The system shall allow patients to reschedule an appointment.
- FR-009: The system shall allow patients to view their medical records.
- FR-010: The system shall allow patients to view prescriptions associated with their medical records.

### Doctor

- FR-011: The system shall allow doctors to view their daily appointments.
- FR-012: The system shall allow doctors to view the medical records of their patients.
- FR-013: The system shall allow doctors to view medical examination results.
- FR-014: The system shall allow doctors to record patient diagnoses.
- FR-015: The system shall allow doctors to create prescriptions for patients.
- FR-016: The system shall allow doctors to update relevant patient medical records.

### Nurse

- FR-017: The system shall allow nurses to view their daily assigned appointments.
- FR-018: The system shall allow nurses to access the medical records of assigned patients.
- FR-019: The system shall allow nurses to record patient vital signs.
- FR-020: The system shall allow nurses to record medical examination results.
- FR-021: The system shall allow nurses to update the medical record with examination results.

### Receptionist

- FR-022: The system shall allow receptionists to register new patients.
- FR-023: The system shall allow receptionists to view available doctors.
- FR-024: The system shall allow receptionists to book appointments for patients.
- FR-025: The system shall allow receptionists to reschedule appointments.
- FR-026: The system shall allow receptionists to cancel appointments.
- FR-027: The system shall allow receptionists to view patient appointments.
- FR-028: The system shall allow receptionists to record patient arrival and check-in.

### Accountant

- FR-029: The system shall allow accountants to create financial operations.
- FR-030: The system shall allow accountants to view and check financial operations.
- FR-031: The system shall allow accountants to record patient payments.
- FR-032: The system shall allow accountants to generate financial reports.
- FR-033: The system shall allow accountants to calculate the clinic's monthly income.
- FR-034: The system shall allow accountants to calculate and manage employee salaries.

### Manager

- FR-035: The system shall allow managers to view system information according to their permissions.
- FR-036: The system shall allow managers to create user accounts for doctors, nurses, accountants, and other employees.
- FR-037: The system shall allow managers to delete or deactivate user accounts.
- FR-038: The system shall allow managers to manage user roles and permissions.

### Security and Access Control

- FR-039: The system shall restrict access to sensitive information based on the user's role.
- FR-040: The system shall prevent unauthorized users from accessing or modifying medical and financial information.
